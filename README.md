## 주요 기능
- 회원가입 / 로그인 / 로그아웃
- 게시물 작성, 목록, 상세 조회
- 댓글 / 좋아요 / 싫어요
- 랭킹
- 관리자 공지 / 알림 / 내 계정 (개발중)

## 기술 스택
- Frontend: HTML, SCSS(CSS), JavaScript
- Backend: PHP (mysqli)
- Database: MySQL (Aiven)
