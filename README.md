PHP와 MySQL로 만든 커뮤니티 게시판입니다.
**접속 IP 및 로그인 기록을 기록합니다.**

## 주요 기능
- 회원가입 / 로그인 / 로그아웃
- 게시물 작성, 목록, 상세 조회
- 댓글 / 좋아요 / 싫어요
- 최근 7일간 가장 인기있는 카테고리/글/사용자 랭킹

## 개발 중
- 관리자 공지
- 알림
- 내 계

## 기술 스택
- Frontend: HTML, SCSS(CSS), JavaScript
- Backend: PHP (mysqli)
- Database: MySQL (Aiven)
- Deploy: Render (Docker)
